Panduan Upload ke GitHub Pages

  1. Buat repository baru di GitHub (misalnya audit-kasir-mds-312).
  2. Upload file ini dengan nama index.html ke root repository, lalu commit.
  3. Buka Settings → Pages, pilih Branch: main dan folder /(root), lalu klik Save.
  4. Akses link GitHub Pages yang muncul, lalu tempel URL Web App /exec pada kolom di atas.
Catatan Apps Script: Karena antarmuka web di-host di GitHub Pages, file Index.html di dalam proyek Google Apps Script bisa dihapus (cukup simpan Kode.gs dan deploy sebagai Web App).
